# Google Search Console - Aguiar Filgueiras

## Estado tecnico validado

- Sitemap: `https://aguiarfilgueiras.com.br/sitemap.xml`
- Robots: `https://aguiarfilgueiras.com.br/robots.txt`
- Robots permite rastreamento: `User-agent: *` e `Allow: /`
- Sitemap referenciado no robots.
- Rotas do sitemap respondem `200`.
- Paginas possuem `robots: index, follow`.
- Canonical e sitemap usam URL final com barra no fim.

## Acao no Search Console

1. Entrar em https://search.google.com/search-console
2. Selecionar ou criar a propriedade:
   - Preferencial: dominio `aguiarfilgueiras.com.br`
   - Alternativa: prefixo de URL `https://aguiarfilgueiras.com.br/`
3. Em `Sitemaps`, enviar:
   - `https://aguiarfilgueiras.com.br/sitemap.xml`
4. Em `Inspecao de URL`, solicitar indexacao das URLs prioritarias abaixo.
