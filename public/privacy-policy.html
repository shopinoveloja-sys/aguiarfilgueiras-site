Política de Privacidade do DriverCash

Última atualização: 11 de maio de 2026

O DriverCash é uma plataforma de organização financeira para motoristas. Esta política explica quais dados coletamos, como usamos essas informações e quais controles o usuário possui.

1. Dados que coletamos

Podemos coletar dados informados pelo próprio usuário, como nome, e-mail, telefone, CPF/CNPJ, receitas, despesas, quilometragem, configurações do veículo, chaves Pix para solicitações de saque e dados necessários para assinatura.

Também podemos coletar dados técnicos básicos, como identificadores de sessão, endereço IP, data e hora de acesso, tipo de dispositivo e registros de segurança.

2. Como usamos os dados

Usamos os dados para autenticar usuários, registrar lançamentos financeiros, calcular métricas, gerar projeções, operar assinaturas, processar indicações, melhorar a segurança e prestar suporte.

3. Compartilhamento

Não vendemos dados pessoais. Podemos compartilhar dados com provedores necessários para operar o serviço, como infraestrutura de hospedagem, autenticação, processamento de pagamentos, envio de SMS e ferramentas de análise operacional.

4. Pagamentos e assinaturas

Pagamentos podem ser processados por parceiros como Mercado Pago. Dados de pagamento são tratados pelo provedor de pagamento conforme suas próprias políticas, enquanto o DriverCash armazena apenas informações necessárias para liberar acesso e acompanhar status de assinatura.

5. Segurança

Aplicamos controles de autenticação, comunicação por HTTPS e segregação de dados por usuário. Nenhum sistema é completamente livre de riscos, mas trabalhamos para reduzir acessos indevidos e preservar a confidencialidade das informações.

6. Retenção e exclusão

Mantemos os dados enquanto a conta estiver ativa ou enquanto forem necessários para obrigações legais, segurança e suporte. O usuário pode solicitar exclusão ou correção dos dados pelo canal de contato abaixo.

7. Direitos do usuário

O usuário pode solicitar acesso, correção, exclusão ou esclarecimentos sobre seus dados pessoais, observadas limitações legais e operacionais.

8. Crianças

O DriverCash não é direcionado a crianças e não deve ser usado por menores de 18 anos.

9. Contato

Para dúvidas de privacidade, suporte ou solicitações sobre dados pessoais, entre em contato pelo e-mail: drivercash.app@gmail.com.
